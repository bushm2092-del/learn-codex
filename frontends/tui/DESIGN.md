# TUI 交互依据

模式：Operate。视觉权威为本地 Codex TUI 的 `history_cell`、`bottom_pane` 与 `app/owned_transcript` 快照。

用户补充的 Codex v0.158.0 截图是本轮布局依据：内容宽度的紧凑会话框、三行起的整宽灰色输入区、紧邻输入区的两行状态/快捷键。输入底色采样为 `#41464b`；整屏背景由终端提供，不修改用户终端主题。

- 原生终端前景和背景，少量 cyan 选择态、red 错误态与 dim 次要信息；不引入图标、渐变或独立欢迎页。
- `>_` 会话头、模型、工作目录；`›` 用户输入、`•` 助手和工具、`└` 工具输出。
- 命令和模型菜单出现在输入区域，方向键选择、Enter 确认、Esc 返回。
- 输入框下面展示状态与快捷键；不编造上下文百分比、token 数、权限保障或恢复能力。
- `model:`、`directory:` 标签弱化，产品名加粗，`/model` 使用 Codex 的蓝色强调。会话框按最长内容收窄，内部最多 56 列。
- 小窗口按终端列宽重新折行，记录保留在前端，可在 transcript 中查看。
- 与 Rust TUI 的技术差异和未支持交互见 README；不把有限子集称为完整复刻。

工作状态沿用 Codex 的两秒文字扫光及圆点明暗变化，与输入区间隔一行。只在运行中刷新；减少动态效果模式保留静态标记和耗时。

鼠标滚轮在聊天记录区域滚动历史，输入框保持固定；不会将滚轮映射到输入历史。到达底部恢复跟随，键盘方向键仍编辑草稿或回忆输入。
