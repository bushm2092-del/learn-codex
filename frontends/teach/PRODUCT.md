## Platform

web

## Product Purpose

Learn Codex 用中文和英文的文章与交互演示讲解 Codex harness。源码教学遵循仓库 AGENTS.md 的真实 Codex 对照要求。

## Operating Context

课程可以匿名阅读。账号使用现有用户名密码或 GitHub 登录，保存章节评论和学习打卡。React 教学站与 Go / PostgreSQL 业务后台分开部署。

## Capabilities and Constraints

用户确认增加独立娱乐模块“天赋测试”：登录后游玩，四项测试各有独立排行榜。反应力按用户参考图，以背景变绿后点击为交互；记忆力采用格子顺序记忆；思考速度采用数字规律判断；专注度采用颜色文字干扰。娱乐数据不进入 Rust 内核会话或章节打卡榜。

## Brand Commitments

Learn Codex 的课程继续沿用现有白底黑字界面。用户明确要求「天赋测试」成为独立模块，导航、布局、视觉与交互可以采用自己的设计体系；首页先选择四项挑战，进入后聚焦当前游戏。保留中英文切换、移动端支持、现有账号和四项玩法。最初参考图规定的核心交互仍为背景变绿后点击，整体外观可重新设计。

用户已批准彩色错落卡片效果图：大厅取消大标题，四项卡片各用薄荷绿、奶油黄、淡紫、浅蓝，高低错落并轻微倾斜；保留翻面与左右选择交互。品牌栏使用小号文字和独立 SVG 图标。

## Evidence on Hand

已有文章、演示、源码快照和登录后台。用户提供反应测试截图。没有医学测评依据，不将娱乐成绩描述成能力认证。
